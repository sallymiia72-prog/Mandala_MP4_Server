# Soul Mandala MP4 Export — Render

Сервис принимает запись мандалы в WebM и возвращает совместимый MP4:

- видео: H.264 (`libx264`);
- звук: AAC;
- пиксельный формат: `yuv420p`;
- `faststart` для быстрой загрузки;
- совместимость с WhatsApp, Telegram, Android и iPhone.

## Развёртывание на Render

1. Создайте новый GitHub-репозиторий, например `Mandala_MP4_Server`.
2. Загрузите в него все файлы из этого архива.
3. Откройте Render.
4. Нажмите **New → Blueprint**.
5. Подключите GitHub и выберите созданный репозиторий.
6. Render прочитает `render.yaml`.
7. Нажмите **Apply**.
8. После запуска скопируйте адрес сервиса, например:
   `https://soul-mandala-mp4.onrender.com`
9. В файле `frontend-integration.js` замените:
   `https://YOUR-RENDER-SERVICE.onrender.com`
   на фактический адрес Render.

## Проверка

Откройте:

`https://АДРЕС-СЕРВИСА.onrender.com/health`

Ответ должен быть:

```json
{"ok":true}
```

## Endpoint

`POST /convert`

Multipart-поля:

- `video` — WebM или MP4;
- `filename` — желаемое имя без расширения.

Ответ: бинарный MP4.

## Важное уточнение

Этот сервер решает совместимость файла: после записи браузером WebM
конвертируется в настоящий MP4.

Чтобы генерировать двухминутное видео на сервере без ожидания двух минут
в браузере, понадобится второй этап: серверный рендер кадров мандалы.
Он требует вынести функцию рисования в отдельный render-модуль.
