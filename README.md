# Soul Mandala — серверный MP4-рендер

Сервис получает дату рождения и создаёт готовый MP4 без записи экрана и без FFmpeg на телефоне.

## Результат

- MP4 H.264 + AAC
- 720 × 900
- 24 fps
- 60 секунд
- совместим с WhatsApp, Telegram, Android и iPhone

## Развёртывание на Render

1. Создайте отдельный GitHub-репозиторий.
2. Загрузите в него:
   - `server.js`
   - `package.json`
   - `render.yaml`
3. На Render выберите **New → Blueprint**.
4. Подключите репозиторий.
5. Нажмите **Deploy Blueprint**.
6. После запуска откройте `/health`. Должно быть `{"ok":true}`.
7. Скопируйте адрес сервиса и вставьте его в `frontend-integration.js` вместо `YOUR-SERVICE`.

## API

`POST /render`

```json
{
  "birthDate": "1969-05-22",
  "duration": 60
}
```

Ответ — готовый MP4.

## Важно

Создание ролика занимает некоторое время и зависит от тарифа Render. Это не мгновенные 2–5 секунд; для 60-секундного видео обычно потребуется от десятков секунд до нескольких минут.
